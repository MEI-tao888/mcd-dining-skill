# 小简（Simple Eat Pet）视觉风格

## 调研范围与原则（20 分钟内）

参考公开可见的快餐餐厅插画、复古 diner 招牌和麦当劳品牌长期使用的色彩语汇，只提炼通用设计原则，不复制任何官方角色、Logo、字标或商标图形。可借鉴的原则是：

- **一眼读懂的轮廓**：用单一主体、夸张比例和清晰负形，让缩小到 180×220 窗口仍能识别。
- **高对比暖色**：红色负责主体识别，黄色表达食物与活力，奶油白平衡画面；深色描边负责在透明背景上保持边界。
- **圆润与厚描边**：圆角、短肢体、少量大形状比细碎装饰更适合小尺寸桌面宠物。
- **轻微复古但保持原创**：使用餐馆招牌常见的两三色平面块、点状高光和友善表情；不使用拱门、官方人物服装、官方包装排版或任何现成标志。
- **可用性优先**：透明背景、无文字水印、无复杂渐变；眼睛和嘴巴留出足够间距，避免缩放后糊成一团。

## 原创设定：小简

“小简”是一只会提醒吃饭的**薯条/小汉堡混合角色**：身体像圆滚滚的小汉堡，头顶插着几根高低错落的薯条；它有奶油白的手套和鞋底，表情是弯眼微笑。薯条的轻微倾斜、两侧不对称手势和一颗小芝麻点是原创识别点。它只传达“轻松想想今天吃什么”，不模仿任何品牌吉祥物。

### 色彩与造型规范

| 用途 | 色值 |
| --- | --- |
| 番茄红主体 | `#D9342B` |
| 薯条黄 | `#F7C948` |
| 奶油白 | `#FFF4DE` |
| 深棕描边 | `#3A2018` |
| 腮红/高光 | `#F27B63` |

主体使用深棕 10–14 px 圆角描边；只用平面色和少量椭圆高光。SVG 画布为 512×512，四周预留透明安全区，适配 180×220 悬浮窗。

## 交付检查

- SVG 保持可编辑、透明画布、无外部字体或图片依赖。
- PNG 为 512×512 RGBA，背景完全透明。
- 图形内不放品牌文字、Logo 或水印。

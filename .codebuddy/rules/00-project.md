# 用餐赛道项目规则（WorkBuddy 自动加载）

1. 先读仓库根 `AGENTS.md` 与 `GLOSSARY.md`；两者冲突时以 `AGENTS.md` 为准。
2. 价格只认 `calculate-price` 的返回；禁止模型自算价格。
3. 写操作（下单/取消/领券/抽奖/商城）前必须展示"动作 + 门店 + 商品 + 金额 + 影响"并等用户确认；一次确认只执行一次写操作。
4. 真实 Token、手机号、地址、他人信息不得落盘、不得进截图；配置只用环境变量占位符。
5. 不硬编码菜单/门店/价格/券；Tool 失败如实说明并走兜底文案，禁止编造。
6. 必须真实调用麦当劳 MCP；没有证据的"完成"按未完成处理。
7. 合规：不贬低麦当劳、不与其他品牌对比；不宣扬不健康饮食/暴食/浪费/拜金/博彩；素材需有使用权。
8. 只做黄金路径；不新增第二场景；不引入数据库/账号体系/支付/复杂前端框架。
9. 确定性逻辑（算价校验、约束求解、券比较、格式化）放进 `skills/<name>/scripts/`，不要交给模型现推。
10. 每轮交付回复：改了哪些文件、为什么改、如何验证、证据（Tool 返回/日志/截图）、下一步。
